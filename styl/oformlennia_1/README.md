# Оформлення сторіс №1

Приклад: `pryklad.jpg` (сторіс про пастель, `stories/pastel/1–5.jpg`).

## Правила
- Шрифт: **Montserrat** (`styl/fonts/Montserrat%5Bwght%5D.ttf`, variable).
  - Перший рядок («гачок»): вага **700**, розмір **50 px**, білий.
  - Продовження: вага **400**, розмір **44 px**, білий.
  - Міжрядковий інтервал 1.32 від розміру шрифту, між жирною і звичайною частиною +8 px.
- Ключові слова — ніжно-рожеві **#F6A8CA** (RGB 246,168,202), і в жирному, і в звичайному рядку.
- Текст по центру, ширина рядка до 960 px на кадрі 1080×1920.
- Висота тексту на кожній сторіс **різна**, текст **ніколи не закриває нігті / обличчя**.
- Безпечні зони Instagram: не вище ~170 px і не нижче ~1780 px.
- Під текстом м'яке затемнення смугою (колір 22,17,15, alpha 140, плавний перехід 260 px) + легка тінь під літерами (blur 9, 55%).
- Емодзі (Noto Color Emoji) в кінці останнього рядка, висота 48 px.

## Як згенерувати
Скрипт `story_style1.py`: функція `mk(кадр, [(текст, BOLD), (текст, REG)], емодзі, y, вихідний_файл)`.
Ключові слова позначаються зірочками: `'Секрет у *молочній підложці*'`.
